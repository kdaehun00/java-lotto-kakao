# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 온라인 코드 리뷰 과정
* [텍스트와 이미지로 살펴보는 온라인 코드 리뷰 과정](https://github.com/next-step/nextstep-docs/tree/master/codereview)


## 로또 자동 (step-1)

### 기능 요구사항

1. 구입 금액 입력 -> 구입 금액에 해당하는 로또 발급 (1장 1000원)
    - 구매 금액 검증 -> double
      - 문자가 들어올 경우: 재입력
      - null일 경우: 재입력
    - 몇 장 발급 가능한지 계산
      - 나누기 -> 몫만 사용
---
2. 로또 숫자 -> 랜덤 6개 (1~45)
   - for문으로 발급 가능한 복권 수만큼 메서드 호출 
   - while문을 사용해서 6개 로또 번호 추천 (Set 사용)
---
3. 당첨 번호 입력받기 (보너스 볼까지)
   - 입력 받기
---
4. 당첨 통계 제공 -> 3개~6개 일치 횟수 (+ 보너스 볼) + 수익률 계산까지
   - 몇 개 맞았는지 계산 (5개 정답인 경우에 if문)
     - 보너스볼이 맞은 경우: 2등
     - 보너스볼이 맞지 않은 경우: 3등
   - 수익률 계산
     - 당첨금액 / 지불한 금액
---

### 테스트 항목

#### 입력 검증

- [x] 구입 금액 검증(14300 -> 14장)
- [x] 입력값이 null 인 경우
- [x] 입력값에 문자가 포함된 경우

#### 로직 검증

- [x] 로또 번호 범위 검증 (1~45)
- [x] 로또 번호 중복 검증
- [x] 번호 일치 개수 검증 (비교. judge) (단, 보너스 볼 따로)
- [x] 로또 컬렉션 자동 생성 검증
- [x] 로또 당첨금 일치 여부 검증 (N개 맞았을 때 돈 맞는지)

## 문자열 덧셈 계산기 기능 요구사항

- [x] 빈 문자열이나 null 입력 시 0 반환
- [x] 숫자 하나를 문자열로 입력할 경우 해당 숫자를 반환한다.
- [x] 숫자 두 개를 컴마 구분자로 입력할 경우 두 숫자의 합을 반환한다 (e.g. 1,2)
- [x] 구분자로 세미콜론 사용 가능
- [x] 구분자로 커스텀 구분자 사용 가능
